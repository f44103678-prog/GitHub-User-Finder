# GitHub User Finder – Поиск пользователей GitHub

**Автор:** Фатимат Созаева

## Описание
Приложение с графическим интерфейсом (tkinter) для поиска пользователей GitHub через официальное GitHub REST API.  
Возможности:
- Поиск пользователей по имени (логину)
- Отображение результатов в виде списка
- Добавление пользователей в **избранное**
- Просмотр избранных пользователей
- Открытие профиля пользователя в браузере (как из результатов, так и из избранного)
- Сохранение избранных пользователей в JSON‑файл (`favorites.json`) с автоматической загрузкой при запуске
- Проверка: поле поиска не может быть пустым

## Как использовать GitHub API
Приложение использует публичный GitHub API без аутентификации:
- Эндпоинт: `https://api.github.com/search/users?q={query}&per_page=20`
- Лимит: для неавторизованных запросов — 60 запросов в час (с одного IP). Для большинства тестов это достаточно.
- При желании можно добавить токен (но в данном проекте не требуется).
